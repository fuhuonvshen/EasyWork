## 一、对话交互 (Chat)

| # | 功能 | 优先级 | 说明 |
|---|------|--------|------|
| C1 | 聊天窗口 | P0 | 消息气泡（用户右/AI左）、Markdown 渲染 |
| C2 | 多轮对话上下文 | P0 | 同会话内记住前文，> 10 轮压缩摘要 |
| C3 | 对话历史列表 | P0 | 左侧栏展示，支持切换、重命名、删除 |
| C4 | 新建/切换对话 | P0 | 自动生成标题（取首条提问前 20 字） |
| C5 | 流式输出 | P1 | Ollama stream=true，逐字显示 |
| C6 | 停止生成 | P1 | 中断正在生成的长回复 |
| C7 | 消息操作 | P1 | [复制] [重新生成] |
| C8 | 跨会话记忆 | P1 | 记住角色、常用术语、偏好 |
| C9 | 语音输入 | P0 | 按住说话→松开发送，复用 SenseVoice |

## 十一、需要你确认的关键决策

| # | 决策点 | 选项 |
|---|--------|------|
| 1 | **你现在手头有什么数据源可用？** | A) 只有 Excel/CSV 本地文件 B) 有 ERP/MES 系统可以查 C) 数据库有接口 D) 都有 |
| 2 | **日报/交接班的数据从哪来？** | A) 已有 Excel 模板，Agent 读 B) 完全靠我口述/打字给 Agent C) 混合 |
| 3 | **语音输入** | A) 保持流式转写 B) 简化：录音→一次性转写→发送 |
| 4 | **流式输出** | A) P0 就做 B) P1 再做 |
| 5 | **Agent 角色定位** | 你最想让它帮你做什么？（多选）□查数据 □写报告 □记待办 □分析异常 □其他____ |
